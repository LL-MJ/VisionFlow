# ADR 0001：单 Worker 与中断恢复

状态：已用于 P1-02；2026-10-27。

## 背景与决定

耗时处理不能放在 HTTP 请求中。P1-02 使用 SQLite 保存任务，Worker 通过 `BEGIN IMMEDIATE` 原子领取一条排队任务；同一存储目录通过操作系统文件锁只允许运行一个 Worker。结果先写临时 JSONL，再替换为最终文件，最后记录成功状态。

Worker 启动并取得锁后，把遗留的 `running` 任务标为 `failed`，清理其未完成结果，不自动重试；用户可为相同视频创建新任务。锁保证不会将同一存储目录中仍在运行的 Worker 的任务误判为中断。

## 取舍与限制

该设计满足本地单机阶段，不需要队列服务；文件锁的效果依赖同一机器和文件系统支持，未验证网络共享目录或多机运行。数据库状态与结果文件不是同一个原子事务：Worker 在文件替换后、状态更新前退出时，下次启动会删除该结果并标记失败，不保留部分成功。没有租约、自动重试或取消功能；后续如需多 Worker 应重新设计。
